K.E.A.N.U. // ANI LEE — AEGIS-STYLE EDITION

This is a modified version of the supplied A.E.G.I.S. browser game structure.
It keeps the cinematic boot, title screen, 3D resonator selection, cutscene,
world map/hub, combat HUD, missions, recruitment, inventory, gear, bosses,
and end screens, but rethemes the visible story around Keanu + Ani Lee.

The Ani Lee face image is embedded into index.html, so you do NOT need to
add the photo separately.

OPTIONAL MUSIC:
Put a file named beatbox_ani_lee.mp3 (or .wav/.ogg) next to index.html.
It will be used as the BATTLE track.

Open index.html in Chrome.
